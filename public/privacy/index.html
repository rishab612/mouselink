MOUSELINK

Privacy, in plain words.

Last updated: November 14, 2026

What MouseLink handles

When you create a remote session, the desktop app connects to the MouseLink relay. Your phone joins that session using the 12-character session code and six-digit PIN. The relay forwards mouse, scroll, and optional keyboard events to the desktop.

What is stored for a session

The relay stores a hash of the session PIN and a short-lived failed-attempt counter. It does not store the mouse or keyboard event stream in the application code. The session state is cleared after the desktop host disconnects and the short cleanup period ends.

Connection details

Remote browser and desktop connections use HTTPS and secure WebSockets (WSS). The relay must read event messages to forward them, so this is transport encryption, not end-to-end encryption. Do not use the keyboard panel to send passwords or other sensitive text.

Accounts and tracking

MouseLink does not create user accounts, set advertising cookies, or include analytics code. Vercel hosts the public website and its download API. Cloudflare operates the realtime relay, and GitHub provides release information and downloadable build artifacts. These providers may process connection information under their own terms and privacy policies.

Your control

Stop the desktop host or disconnect the phone to end a session. The host accepts one phone at a time. The local desktop dashboard is meant to remain on the computer and should not be published to the internet.
